# Plataforma JavaScript – Proz

Ambiente web educacional desenvolvido para apoiar o aprendizado e a prática de **JavaScript** no curso de **Desenvolvimento de Sistemas da Proz**.

## Sobre o projeto

A plataforma foi criada como material de apoio às aulas de JavaScript, oferecendo aos alunos um ambiente organizado para revisar conceitos, consultar exemplos e realizar exercícios práticos.

O objetivo é facilitar o aprendizado por meio da prática, permitindo que os conteúdos apresentados em sala de aula sejam explorados através de pequenos códigos e desafios.

## Objetivos

* Reforçar os conceitos apresentados durante as aulas;
* Incentivar a prática de programação;
* Desenvolver o raciocínio lógico;
* Facilitar a compreensão da sintaxe do JavaScript;
* Permitir que os alunos experimentem e modifiquem códigos;
* Servir como material de revisão para atividades e avaliações.

## Conteúdos abordados

A plataforma apresenta exercícios relacionados aos fundamentos de JavaScript, incluindo:

* Tipos de variáveis;
* Declaração de variáveis com `let`, `const` e `var`;
* Atribuição de valores;
* Objetos;
* Acesso a propriedades com notação de ponto;
* Chamadas de métodos;
* Operadores de atribuição;
* Operadores aritméticos;
* Operadores de comparação;
* Operadores lógicos;
* Operador ternário;
* Uso do `console.log()`;
* Exercícios de lógica utilizando JavaScript.

Novos conteúdos e atividades poderão ser adicionados conforme o avanço das aulas.

## Tecnologias utilizadas

O projeto utiliza tecnologias fundamentais do desenvolvimento web:

* **HTML5** – estrutura das páginas;
* **CSS3** – estilização e organização visual;
* **JavaScript** – lógica, interatividade e exercícios.

## Como utilizar

1. Faça o download ou clone o projeto;
2. Abra a pasta do projeto em um editor, como o Visual Studio Code;
3. Abra o arquivo `index.html` no navegador;
4. Escolha o conteúdo ou atividade desejada;
5. Leia as orientações e exemplos;
6. Resolva os desafios propostos;
7. Experimente modificar os códigos para observar diferentes resultados.

Os exercícios também podem ser reproduzidos em compiladores JavaScript online, como o OneCompiler.

## Metodologia

A proposta da plataforma é trabalhar com a sequência:

**Aprender → Observar → Praticar → Modificar → Experimentar**

O aluno não deve apenas copiar os exemplos. É recomendado modificar valores, criar novas variáveis, testar operadores e observar como cada alteração interfere no resultado do programa.

## Público-alvo

Projeto destinado principalmente aos alunos do curso de **Desenvolvimento de Sistemas da Proz**, especialmente aqueles que estão iniciando seus estudos em JavaScript e lógica de programação.
